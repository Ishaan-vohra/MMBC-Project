# MMBC-Project
Repository for Ishaan's work on the Fermilab MMBC project.

This repo contains a Geant4 simulation using neutrino DUNE flux files. 
The Geantinos' initial positions and momenta are given by the flux files, 
and they are then propagated to several detectors placed at different 
locations. The properties of the neutrinos measured by the detectors is 
then recorded and saved to several sets of ROOT histograms.
